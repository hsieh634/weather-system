# 全球氣象預測系統

多模式融合 + 機器學習在地修正 + 劇烈天氣／颱風／聖嬰監測，並用真實資料驗證每一天的準確率。
全部資料來源免費、免金鑰（台灣官方警報除外）。

## 快速開始

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt     # macOS/Linux：.venv/bin/python
.venv\Scripts\python cli.py serve                           # 打開 http://127.0.0.1:8000
```

命令列：

```bash
python cli.py forecast 台北        # 文字版 16 天預報
python cli.py verify 台北          # 這個地點第 1~7 天的實測準確率
python cli.py train 台北           # 強制重新訓練
python cli.py tropical             # 全球颱風／颶風
python cli.py enso                 # 聖嬰／反聖嬰
```

地點可以輸入城市名稱（中英文皆可）或「緯度,經度」。

## 系統架構

```
weather_system/
  data_sources.py   地名搜尋、7 個全球模式即時預報、系集預報、歷次預報存檔、ERA5
  stations.py       NOAA GHCN 地面氣象站實測（有測站就用它當正確答案）
  ensemble.py       依歷史誤差計算各模式權重並加權融合
  correction.py     機器學習在地修正（MOS）＋ 第 1~7 天誠實驗證
  verification.py   成績報表
  severe.py         雷雨、冰雹、龍捲風環境、豪雨、強風、降雪、凍雨、高溫、低溫、濃霧
  tropical.py       颱風／颶風／熱帶氣旋（GDACS、NOAA NHC）
  enso.py           聖嬰／反聖嬰（NOAA CPC Niño 3.4、ONI）
  alerts.py         官方警報（美國 NWS；台灣中央氣象署需金鑰）
  forecast.py       總流程
  maps.py           天氣地圖格點預報、颱風路徑與預報錐
  typhoon_event.py  颱風／豪雨事件：各縣市災害程度與停班停課機率
app.py              FastAPI 網頁伺服器
static/             網頁介面（app.js 主頁、weathermap.js 地圖、event.js 颱風事件）
cli.py              命令列工具
```

### 預報怎麼產生

1. **抓 7 個全球模式**：ECMWF、GFS、ICON、JMA、ARPEGE、GEM、UKMO（透過 Open-Meteo）。
2. **加權融合**：依這個地點過去的誤差給權重，誤差越小權重越大。
3. **機器學習修正**：用約兩年「各模式前一天真正發出的預報」對照「實際觀測」，
   以梯度提升樹學出系統性偏差（例如某模式在盆地總是低估最高溫）。
4. **自動選方法**：在獨立的一段資料上比較「最佳單一模式／加權融合／機器學習」，每個變數各選最準的。
5. **系集預報**：ECMWF 51 成員 + GFS 31 成員，算出降雨機率與溫度 80% 區間。

### 準確率怎麼算（不灌水）

時間切成三段，模型永遠看不到它被考的資料：

```
[ 訓練 60% | 選方法 20% | 考卷 20% ]
```

考卷期用 **1~7 天前真正發出的預報** 計分，所以「第 3 天 ±2°C 命中率 84%」
代表：這個系統在這個地點預報 3 天後的最高溫，歷史上有 84% 的日子誤差在 2°C 以內。

正確答案優先使用附近 25 km 內的 NOAA 公開氣象站；沒有時使用 ERA5 再分析（約 25 km 格點）。

## 天氣地圖

網頁最上方的互動地圖（`static/weathermap.js`、`weather_system/maps.py`）：

- **8 個圖層**：溫度、降水量（前 3 小時累積）、風速、陣風、氣壓（含等壓線）、雲量、濕度、雷達
- **預報動畫**：按播放鍵或拖曳時間軸，看未來 7 天、每 3 小時的變化，畫面在兩個時間之間平滑過渡
- **風線**：白色粒子沿預報風向流動，可在工具列開關
- **颱風路徑**：實線為已走過路徑、虛線為預報路徑、半透明區域為預報錐，颱風圖示會隨時間軸移動
- **雷達**：RainViewer 過去 2 小時實測回波，可播放
- 滑鼠移到地圖上可讀取該點數值；平移到別的區域會自動下載該區資料

格點資料為 13×13 個點（約 2°×2.5° 間距），用雙線性內插畫成連續色彩；
解析度比專業氣象網站使用的原始模式檔粗，放大後降雨分布會較粗糙。
所有圖形都由本程式自行繪製，資料來自 Open-Meteo、GDACS、RainViewer，未使用其他網站的圖片或程式碼。

## 颱風事件與停班停課機率

颱風路徑進入台灣 600 km 內，或任一縣市達標機率 ≥ 30% 時，頁面最上方會出現事件卡片
（`static/event.js`、`weather_system/typhoon_event.py`）。點開後可依日期切換：

- **停班停課機率**：ECMWF 51 組 + GFS 31 組系集預報中，達到《天然災害停止上班及上課作業辦法》
  參考標準（平均風 7 級或陣風 10 級，或 24 小時雨量 200 mm）的比例
- **災害程度**：依陣風、平均風、雨量分 0～4 級，並標示強風、豪雨淹水、山區土石流風險
- 點縣市可看陣風、平均風、雨量的中位數與偏強情境（第 90 百分位）

限制：代表點只取各縣市政府附近平地；全球模式格點約 25 km，強颱陣風常被低估；
機率未經歷史停班停課紀錄校正。實際是否停班停課以各縣市政府及行政院人事行政總處公告為準。

## API 額度

Open-Meteo 免費版每分鐘 600、每小時 5,000、每天 10,000 次（多地點或多變數的請求會算成多次）。
訓練新地點約用 200 次、地圖每個新區域約 169 次、颱風事件約 22 次。額度用完（HTTP 429）時，
系統會先改用已下載的舊資料；沒有舊資料時，伺服器回傳 409 與要下載的請求清單，
由訪客的瀏覽器直接向 Open-Meteo 下載（`static/relay.js`），回傳 `/api/relay` 存進快取後再重新計算。
伺服器只接受自己發出、15 分鐘內的請求。雲端主機的共用 IP 額度常被別人用完，這個機制讓網站仍可正常運作。
本機測試可設環境變數 `FORCE_RELAY=1` 模擬伺服器額度已用完；有付費金鑰則設 `OPEN_METEO_API_KEY`。

## 已知限制

- **不可能 100%**：大氣是混沌系統，誤差隨時間指數放大。7 天後準確率明顯下降，10 天以上僅供趨勢參考。
- **龍捲風、冰雹**：模式格點解析不出單一雷雨胞，系統提供的是「環境是否有利」的風險，不是確定預報。
- **台灣測站**：NOAA 沒有公開近年台灣測站資料，台灣地點以 ERA5 為正確答案；
  若要改用中央氣象署測站，需申請金鑰並另外串接。
- **颱風路徑**：目前顯示即時位置、強度與距離；官方路徑預報請點連結到 GDACS／NHC。
- **台灣官方警報**：到 https://opendata.cwa.gov.tw/user/authkey 申請免費金鑰，
  設定環境變數 `CWA_API_KEY` 後重新啟動。這部分因沒有金鑰尚未實測。
- 修正模型存在 `trained_models/`，每 30 天自動重新訓練；`cache/` 是下載快取，可隨時刪除。
